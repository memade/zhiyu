# 直予 / Zhiyu 0.1.0

正式版，build 13。支持简体中文、繁体中文和英文。

局域网支持消息与文件传输；蓝牙支持短文字和回执，不传文件。

- Android 7.0+ / arm64：[APK](https://github.com/memade/zhiyu/releases/download/v0.1.0/Zhiyu-0.1.0-android-arm64.apk)，已使用发行密钥签名。
- macOS 13+ / Apple Silicon：[DMG](https://github.com/memade/zhiyu/releases/download/v0.1.0/Zhiyu-0.1.0-macos-arm64.dmg)，使用 Developer ID 签名，并通过 Apple 公证。
- Windows 11 / x64：[便携 ZIP](https://github.com/memade/zhiyu/releases/download/v0.1.0/Zhiyu-0.1.0-windows-x64.zip)，未做 Authenticode 签名。完整解压后运行 `product\zhiyu.exe`。

从 RC2 更新时，应用标识和 Windows 数据目录已变更，旧数据不会自动迁移。请保留旧 App 和数据，无需先卸载；详见[安装说明](https://github.com/memade/zhiyu/blob/main/INSTALL.md)。

下载后核对 [SHA256SUMS](https://github.com/memade/zhiyu/releases/download/v0.1.0/SHA256SUMS)。iOS 不在本次公开下载范围，App Store 上架准备中。
